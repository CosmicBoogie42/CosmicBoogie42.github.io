# Tiff Célice, tech recruiter

My portfolio: who I recruit, what I've done, and how to reach me.

**Live site:** https://cosmicboogie42.github.io/

## What's on the page

- **Right now:** my current role and how I work.
- **Selected work:** case studies with the results behind them.
- **Who I recruit:** engineers, designers, product managers and hiring managers, plus everything else.
- **Writing:** articles I've written about CVs and hiring.
- **Career:** my roles, most recent first.

## How it's built

The whole site is one file, `index.html`, with the styles inline. There is no framework, no JavaScript and no build step.

- Responsive down to phone width, with light and dark mode that follows the device setting.
- Visible keyboard focus and semantic headings and tables.
- One typeface, Hanken Grotesk, loaded from Google Fonts with system fonts as a fallback.
- No animation.

## Edit it

1. Open `index.html` in this repository and choose the pencil icon.
2. Make the change and commit it to `main`.
3. GitHub Pages redeploys on its own. Give it a few minutes, then do a hard refresh.

To preview locally, open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000.
